# My Resume 

A simple personal resume website built with HTML. The website presents my professional profile, education, work experience, technical skills, accomplishments, and additional information.

## 📌 Overview

This project is a static resume webpage titled **"My Resume"**. It introduces me as a web developer and provides an overview of my academic background, professional experience, skills, and achievements.

## ✨ Features

* Personal profile picture
* Professional summary
* Education history
* Work experience
* Technical skills
* Accomplishments
* Contact page

* Copyright footer

## 📁 Project Structure

```text
project/
│
├── index.html
│
├── assets/
│   └── My picture.jpg
│
└── public/
    ├── contact.html
    └── about.html
```

The `index.html` file references a profile image in the `assets` directory and links to the `contact.html` and `about.html` pages inside the `public` directory.

## 🚀 How to Run

Since this is a static HTML project, no special installation or dependencies are required.

1. Clone or download the project.
2. Make sure the `assets` and `public` folders are in the correct locations.
3. Open `index.html` in a web browser.
